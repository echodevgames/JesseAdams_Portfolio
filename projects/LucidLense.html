Lucid Lens — State-Driven Gameplay & UI

A collaborative Unreal Engine project exploring perception, interaction, and state-driven gameplay through mask-based mechanics. My work focused on Blueprint state management, UI systems, and ensuring clear, consistent UX across gameplay modes.

Project Overview

Lucid Lens is a team-based Unreal Engine project built around the idea of switching player perception and interaction modes using masks. Each mask represents a distinct gameplay state, altering rules, UI feedback, and available interactions.

  • Unreal Engine 5
  • Blueprint State Management
  • UI / UX Design
  • Gameplay Systems
  • Team Collaboration

My Contributions

  • State Manager (Blueprint)
    Designed and implemented a centralized state manager to control mask-based gameplay modes and transitions.
  • Mask Mode Switching
    Implemented clean, deterministic switching logic to ensure consistent behavior across gameplay, UI, and interaction systems.
  • UI & UX Flow
    Built and refined UI flows to clearly communicate active states, available actions, and player feedback without overwhelming the screen.
  • Team Integration
    Worked closely with teammates to align gameplay logic, UI expectations, and system boundaries across Blueprint systems.
